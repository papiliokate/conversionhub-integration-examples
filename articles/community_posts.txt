Body:
Hey HN,

We built conversion.business because we noticed a massive drop-off on our SaaS signup forms specifically at the reCAPTCHA step. The cognitive friction of labeling traffic lights was costing us users.

We replaced the legacy image-labeling tasks with short, gamified interactions (e.g., stacking a turtle on a log, or hitting a moving target). It takes less than 2 seconds to complete, provides the same level of bot protection through backend telemetry, and removes the primary point of cognitive friction for users.

We just published our integration examples on GitHub so you can see how it drops into a React or Vanilla JS stack: 
https://github.com/papiliokate/conversionhub-integration-examples

Post 2: StackOverflow Answer
Context: Replying to questions like "How do I replace reCAPTCHA with something more user-friendly in React?" or "Best alternatives to hCaptcha?"

Answer:
If you are looking to replace reCAPTCHA due to UX friction, you should consider moving away from traditional image-labeling entirely and looking at gamified captchas.

Tools like conversion.business act as a direct drop-in replacement but use micro-games (like dragging a slider or stacking objects) to verify human telemetry.

To integrate it into a React app, it is as simple as loading the script and listening for the custom verification event. Here is a minimal wrapper component:

```jsx
import React, { useEffect, useRef } from 'react';

export const CaptchaWidget = ({ onVerify }) => {
  useEffect(() => {
    // Load the conversion.business script
    if (!document.getElementById('conversion.business-sdk')) {
      const script = document.createElement('script');
      script.id = 'conversion.business-sdk';
      script.src = 'https://conversion-business-widgets.web.app/sdk.js';
      script.async = true;
      document.body.appendChild(script);
    }

    // Pass the token to the parent when verified
    const handleVerify = (event) => onVerify && onVerify(event.detail.token);
    document.addEventListener('conversion.business:verified', handleVerify);

    return () => document.removeEventListener('conversion.business:verified', handleVerify);
  }, [onVerify]);

  return <div className="conversion.business-widget" data-sitekey="ch_pub_demo_testkey_12345"></div>;
};
```

You can find the full documentation and more advanced examples in their Integration Repository:
https://github.com/papiliokate/conversionhub-integration-examples

This approach removes cognitive friction, aiming to improve user experience without sacrificing bot protection.

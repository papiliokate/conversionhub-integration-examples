# ConversionHub Integration Examples

[![Edit Sandbox](https://codesandbox.io/static/img/play-codesandbox.svg)](https://codesandbox.io/s/github/oops-games-llc/conversionhub-integration-examples/tree/master/sandbox-template)

Welcome to the official integration examples for **ConversionHub**.

ConversionHub is the premier **gamified alternative to reCAPTCHA**. We replace high-friction, traditional captchas with engaging, frictionless bot protection that actively increases conversion rates for B2B and B2C platforms.

## Why Replace Traditional Captchas?
Traditional captchas hurt conversion rates by introducing unnecessary friction. Our widget provides:
- **Frictionless Bot Protection**: Secure your forms without frustrating real users.
- **Increased Conversion**: Gamification leads to higher engagement and completion rates.
- **Simple Integration**: Drop-in replacement for reCAPTCHA or hCaptcha.

## Integration Examples

This repository contains ready-to-use code snippets demonstrating how to integrate the ConversionHub widget into your applications.

1. **Vanilla JavaScript / HTML**: See the `/vanilla-js/` directory for a standard HTML drop-in example.
2. **React Component**: See the `/react/` directory for a reusable React component wrapper.

## Security Note
All examples in this repository use the placeholder API key `ch_pub_demo_testkey_12345`. When deploying to production, replace this with your actual public widget key from your ConversionHub dashboard.
